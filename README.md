# MDX support for Consulo

MDX (Markdown with JSX and ESM): the Markdown parser of the MDX flavour (JSX flow/text elements, `{expressions}`, ESM
`import`/`export` blocks), the embedded JavaScript/JSX as one module (template data language), highlighting with a
JavaScript layer, color settings page, commenting (`{/* */}`), typing assistance (tag and brace closing, Enter in JSX and
code fences), `import`/`export` completion, formatter, code fence formatting, inspection suppression.

Requires the JavaScript, XML and Markdown plugins.
